# Capability Absorption Matrix

> 기준일: 2026-08-12
> 목표 상태: 모든 target capability가 Verified
> 판정 근거: runtime composition path, focused repository tests, provenance ledger 재감사

## 상태 정의

| 상태 | 의미 |
|---|---|
| Missing | 현재 runtime 경로가 없다. |
| Partial | 일부 행동이나 파일은 있으나 조합, 범위 또는 test가 불완전하다. 안전 요구가 미충족인 구현도 포함한다. |
| Connected | target behavior가 실제 runtime composition path에 연결되어 있고 직접 test가 있다. |
| Verified | target behavior contract, integration, negative test, evidence가 모두 있다. |

## 흡수 판정 규칙

상태 전이는 다음 순서만 허용한다.

    Missing
      -> Partial
      -> Connected
      -> Verified

- 파일이나 type만 추가된 상태는 Partial이다.
- kernel의 실제 composition path에 연결되면 Connected다.
- happy path와 error path test, receipt evidence, provenance가 모두 있으면
  Verified다.
- upstream benchmark 숫자나 README 주장만으로 상태를 올리지 않는다.
- Corelay Code의 기존 더 강한 behavior는 source inspiration의 더 좁은 behavior로
  대체하지 않는다.
